# Requirements: Shuana Bus Platform

## Functional Requirements

- **REQ-01**: Express.js REST API providing bus schedule search, route details, and booking persistence.
- **REQ-02**: Razorpay order generation and payment verification endpoints.
- **REQ-03**: RedBus styled unified search capsule with origin, destination, animated swap, and date picker.
- **REQ-04**: Dedicated Bus Details page with exact 2D dual vertical bus deck layout (Lower & Upper deck).
- **REQ-05**: Realistic sleeper berth states: sold, female-only sold, available green, and selected violet/blue.
- **REQ-06**: Photo gallery, highlights, cancellation policy table, and boarding/dropping points.
- **REQ-07**: Interactive step navigation: Select seats ➔ Board/Drop point ➔ Passenger Info ➔ Razorpay Payment.
- **REQ-08**: Instant Confirmed Digital Boarding Pass with scannable QR code and WhatsApp/print share.
- **REQ-09**: Webapp Dark Mode and Light Mode switcher with persistent preference.
- **REQ-10**: Royal Electric Violet palette tokens and featured destination banner (Chyll Goa 4D/3N).
