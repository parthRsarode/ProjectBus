# Project: Shuana Bus (redBus Inspired Platform)

## Overview
Shuana Bus is a modern, production-grade online bus booking web platform featuring an Express.js backend API, redBus-inspired UI with authentic 2D dual vertical bus decks, Razorpay payment gateway integration, instant scannable digital boarding passes, full Dark/Light theme switching, and Royal Electric Violet branding.

## Core Value
Empower travelers with real-time bus discovery, realistic visual seat picking (Lower & Upper decks with exact berth states), transparent cancellation policies, and instant confirmed digital ticket issuance.

## Technology Stack
- **Frontend**: HTML5, Vanilla CSS3, Modern ES Modules, Vite, Canvas-Confetti
- **Backend**: Node.js, Express.js, Cors, Dotenv, Razorpay SDK, Crypto
- **Storage**: Persistent JSON database (`server/data/bookings.json`, `server/data/buses.js`)
- **Theme**: Royal Electric Violet (`#7C3AED` / `#8B5CF6`) with full Light & Dark mode support
